# Sistem Informasi Akuntansi Pembagian Komisi Kapster pada Usaha Barbershop Berbasis Web

## Deskripsi

Aplikasi ini merupakan sistem informasi akuntansi berbasis web yang digunakan untuk mengelola data kapster, layanan, transaksi barbershop, serta menghitung dan menyajikan informasi pembagian komisi kapster secara otomatis.

## Teknologi

- HTML
- CSS
- JavaScript
- Supabase
- PostgreSQL
- Git
- GitHub

## Fitur

- Dashboard
- Master Data Kapster
- Master Data Layanan
- Transaksi Barbershop
- Perhitungan Komisi Otomatis
- Riwayat Transaksi
- Laporan Komisi Kapster

## Perhitungan Komisi

Nilai komisi dihitung dengan rumus:

Komisi = Subtotal × Persentase Komisi

Contoh:

Rp30.000 × 40% = Rp12.000
